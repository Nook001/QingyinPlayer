# 验证记录

离屏检查是 `bash scripts/qml-interaction-check.sh`（`QT_QPA_PLATFORM=offscreen`）。它覆盖列表复用后的曲目 ID、排序表头、切页后的查询与滚动字段，以及进度条的键盘 seek。拖动进度时，绑定只在未按下时接受后台进度。

这些检查不是桌面鼠标或触摸板复现。下面两项都还没有在真实指针设备上补记：

| 场景 | 离屏 | 桌面鼠标 / 触摸板 |
| --- | --- | --- |
| 复用后的双击仍使用曲目 ID | 已覆盖 | 未记录 |
| 排序后仍按曲目 ID 播放 | 已覆盖表头信号 | 未记录 |
| 切页后保留查询与滚动位置 | 已覆盖字段 | 未记录 |
| 进度条左右键按 5 秒 seek | 已覆盖 | 未记录 |
| 拖动进度时不被后台进度反向 seek | 已覆盖绑定条件 | 未记录 |

长列表在快速滑动时是否会造成指针假死，仍然是未复现的假设。曲目表和集合浏览器已经使用虚拟化列表，不能据此认为假死已经消除，也不能把委托复用时的状态串扰当成根因。
